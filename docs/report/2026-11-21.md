## 確認項目
### 優先度高
- FN033 申請一覧画面の「詳細」押下時の遷移先
    - 状況
    要件シート
    ```
    /attendance/detail/{id}
    ```

    提供Blade
    ```
    /application/{application_id}
    ```
    となっており、要件外の遷移が提供Bladeで指定されている状況です。
    変更可否を確認させてください。

- PG09 管理者勤怠詳細画面のURL不整合
    - 状況
    要件シート
    ```
    /admin/attendance/{id}
    ```

    提供Blade
    ```
    /attendance/{id}
    ```
    - 懸念
    管理者画面なのに一般ユーザー向け画面へ遷移している
    要件シートと実装が一致していない

### 優先度中
- 管理者修正時の履歴管理仕様
    - 確認したいこと
    パターン1
    ```
    管理者が一般ユーザーを修正
    ↓
    attendance_records 更新のみ
    ```
    なのか

    パターン2
    ```
    管理者が一般ユーザーを修正
    ↓
    application 作成
    ↓
    承認済み履歴として残る
    ```
    なのか

    - 管理者自身の勤怠修正
    ```
    管理者
    ↓
    自分の勤怠を修正
    ↓
    直接更新
    ```
    なのか

    ```
    管理者
    ↓
    自分の勤怠修正
    ↓
    申請履歴作成
    ↓
    承認済み
    ```
    なのか

### 優先度低

- ログアウト後の遷移
    - 状況
    要件シートではログアウト後の遷移先の記載はなく、現状
    ```
    /（Welcome画面）
    ```
    へ遷移となっています。

    - 確認事項
    通常の勤怠アプリを考えると/（welcome）に遷移すると、次の利用ができないため、ログイン画面に遷移させたほうがいいのではと考えています。

- 勤務時間・休憩時間の病の扱い
    - 確認内容
    例
    ```
    出勤：16:08:28
    退勤：17:04:06
     
    勤務時間：0:55:38
    ```
    を表示するとき、

    ```
    0:55（切り捨て）
    ```
    なのか、

    ```
    0:56（切り上げ）
    ```
    なのか。
    - 現状
    ```
    diffInMinnutes()で実装したため、分単位での差分を扱っており、切り捨てで実装しています。
    ```
