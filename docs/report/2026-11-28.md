#### 2. 休憩時間バリデーションメッセージの重複表示

状況

休憩時間に対する入力エラー発生時、

```text
休憩時間が不適切な値です
休憩時間が不適切な値です
```

のように同一メッセージが複数表示されることを確認した。

原因調査結果

```text
new_break_in
new_break_out
```

のエラーをそれぞれ表示しているため、
同一内容のメッセージが重複して表示されている。

確認したいこと

```text
提供Bladeの修正は禁止のため、
重複表示は仕様として許容してよいか。

または、

Blade修正を行い、
同一メッセージを1回のみ表示する対応を実施してよいか。
```
